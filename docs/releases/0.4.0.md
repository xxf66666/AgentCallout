# AgentCallout v0.4.0

2026-09-13。浏览器 DOM 定位版本，功能提交 `1ba5778`，设计见 [ADR-0011](../adr/0011-browser-dom-locator.md)。

## 本版功能

- 可选浏览器运行时：固定 `playwright-core` 1.63.0 + 用户已装 Chrome（channel `chrome` 或显式可执行路径），不下载 Chromium；`browser install/status` 显式管理，定位在受控子进程中执行。
- `locate-dom`（CLI）/ `locate_dom`（MCP，工具总数 12）：CSS selector、文字（NFKC/统一空白/CJK 空白折叠，exact/contains）与可访问性名称（启发式 accname + role 过滤）三种定位模式。
- 候选 rect 为顶层页面 CSS 像素（`deviceScaleFactor: 1`，截图像素 == CSS 像素），iframe 逐层偏移换算并附 framePath；文字候选取最内层匹配。
- 每次定位写入全页 PNG 截图并绑定 SHA-256；页面状态（URL、标题、视口、scrollX/Y）随候选返回；返回前复核磁盘截图 hash。**页面任何变化后旧坐标失效**，批注必须使用当次截图。
- 定位为只读操作；候选默认上限 100 并报告 `totalCandidates`/`truncated`；浏览器缺失、页面崩溃与超时显式失败（`DOM_RUNTIME_NOT_READY`、`DOM_LOCATE_FAILED` 等）。

## 已知边界与后续

- 可访问性名称为启发式计算（aria-label/title/placeholder/alt/label 文本），非完整 ACC 规范。
- fixed 元素 rect 绑定截图时刻的滚动位置；跨浏览器引擎（Firefox/WebKit）与真实公网页面的深checked验收仍待 0.4.x 扩展。
- 无 Chrome 的环境跳过 DOM 集成测试并明确报告。
- 下一阶段：0.4.x 协作与平台完善（三平台 CI、working copy/fork/diff、Codex Marketplace 超时、系统截图/GUI 评估），见[路线图](../roadmap.md)。
