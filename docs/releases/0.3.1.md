# AgentCallout v0.3.1

2026-09-13。跨 AI 一键交接包版本，功能提交 `df4d115`，设计见 [ADR-0010](../adr/0010-cross-ai-handoff-package.md)。

## 本版功能

- `create-handoff`（CLI）/ `create_handoff`（MCP）：把已验证的 annotate sidecar 打包为普通目录——批注 PNG、完整 JSON、`manifest.json`（角色 + SHA-256 + 字节数的创建时快照）、`summary.json` 安全摘要、`HANDOFF.md` Markdown 入口，默认附原图（`--no-original` 显式声明不可重渲染/修订）。
- `verify-handoff`（CLI）/ `verify_handoff`（MCP）：校验 manifest 结构、逐文件 hash 与打包 sidecar 对输出的完整性；问题以 `HANDOFF_FILE_MISSING`、`HANDOFF_HASH_MISMATCH`、`HANDOFF_MANIFEST_INVALID` 逐条列出。
- 包内保留原文件名：sidecar 相对引用与 `.revN` 修订链天然有效，接收方可直接继续修订；MCP 工具总数 9 → 11。
- 创建经临时目录 + 原子 `rename` 发布：并发创建仅一方成功；失败不留半成品；保留名（`manifest.json`/`summary.json`/`HANDOFF.md`）冲突显式报 `HANDOFF_NAME_CONFLICT`。
- 接收方不安装 AgentCallout 即可阅读；安装后可校验、重渲染、修订。
