# AgentCallout v0.6.0

2026-09-14。批量批注版本（roadmap 批量项，版本号因 0.5.1 补丁顺延），功能提交 `cee0d8f`。

## 本版功能

- `annotate --batch <manifest>`（CLI）/ `annotate_batch`（MCP，工具总数 15）：一次调用批注 1–32 张图。
- 清单为普通 JSON：`items[]`（每项 = `input` 图片路径 + 内联 `spec` 或 `specPath` 文件引用）+ 可选 `numbering` 与 `continueOnError`。
- **跨图连续编号**：`numbering: "continuous"` 按遍历顺序把所有 numbered-callout 重排为跨图 1..N（specPath 引用先加载再编号）；`per-image` 保持 spec 原样。
- 执行语义：逐图顺序、单图失败隔离（其余成功图不受影响、无半成品）；默认 fail-fast，`continueOnError`/`--continue-batch` 显式继续并逐图汇总失败原因。
- MCP：返回逐图汇总 JSON（outputPath/sidecarPath/annotationCount/warnings + failures）+ **至多一张聚合 contact-sheet 预览**（沿用 512px/64KiB 图片契约）；spec 仅接受内联（specPath 为 CLI 专属，避免 MCP 借其越界读文件）。
