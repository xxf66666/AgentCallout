# AgentCallout v0.5.1

2026-09-14。Windows 补丁版本：修复 DOM 定位在 Windows 上的临时目录硬编码缺陷（`locateWithRuntime` 的 `mkdtemp` 回退到 `"/tmp"`，Windows 无此目录，定位必然 ENOENT）。改用 `node:os` `tmpdir()`。另含 v0.5.0 的 CI 矩阵修复（Node 20→22/24、OCR 真实安装专用 job、失败日志/匿名 issue 报告通道）与 OCR 真实安装测试自包含化。

## 证据

- 缺陷由 CI 矩阵 Windows 格真实暴露（匿名 issue 通道 #6/#7：`mkdtemp '\tmp\agent-callout-dom-XXXXXX' ENOENT`），本机 macOS 无法复现。
- 修复后：ubuntu 容器内 OCR 真实安装测试 15/15 通过；本机完整 verify 与 DOM 真实定位 probe 通过；CI 全矩阵以 issue 报告通道复核。
- Node 支持线自本系列起为 `>=22`（v0.5.0 决策）。
