# AgentCallout v0.4.1

2026-09-13。working copy、fork 与 revision diff 版本，功能提交 `8e23ed3`（+ `3868fa9` 根目录符号链接修复），设计见 [ADR-0012](../adr/0012-working-copy-fork-diff.md)。

## 本版功能

- `fork-lineage`（CLI）/ `fork_lineage`（MCP）：把整个 lineage（base 与全部 `.revN` 的 JSON+PNG、原图）拷贝到新目录，写入 `fork.json`（模式 `fork`/`working-copy`、源 lineageId 与源 sidecar SHA-256、时间戳、逐文件 SHA-256）。**不重写 sidecar 字节**，修订链校验原样保留。
- `diff-revisions`（CLI）/ `diff_revisions`（MCP）：两个已验证 sidecar 按稳定 ID 对比（`added`/`removed`/`changed` 含变化字段与截断的新旧值），并报告 lineage 关系 `same-lineage`/`forked`/`unrelated`；MCP 工具总数 14。
- 自动 merge 评估结论（ADR-0012）：推迟——需要三方语义与逐 ID 冲突规则；`fork` + `diff` + 手工 `revise` 覆盖当前协作工作流。
