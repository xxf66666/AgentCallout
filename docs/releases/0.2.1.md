# AgentCallout v0.2.1

2026-09-06。密集批注与排版质量版本，核心提交 `9384df7`，客户端显示兼容修复 `a3812a5`。

## 本版功能

- AnnotationSpec 1.1 批量规划说明框，提前保护全部目标，避让固定文字、说明框及编号。
- 普通箭头、说明框箭头及编号引线支持折线路径，包含描边和箭头头部碰撞检查。
- 改进边角、小目标、长文字与空间不足时的确定性降级，返回稳定 warning 和完整路由几何。
- 预览提供七项可复算的像素指标；仍为每次最多一张、最长边 512 px、最多 64 KiB。
- 修复当前 Codex 不接受 `low` 图片显示标记的问题，改用 `auto`；像素预算不变。
- AnnotationSpec 1.0 继续使用旧渲染路径，固定 PNG 回归通过。浅色说明框和语义配色沿用既有 1.1 能力。

## 已知边界与后续

- 布局器只保护传入的 target 区域。14px 复选框目标不自动包含其旁边的文字；需要一起保护时应将说明文字纳入目标矩形。warnings 为空不等于所有未标注源内容无遮挡，仍需视觉复核。
- 有界布局不保证所有输入都有无冲突解；拥挤或极端样式会报告降级，不能忽略裁切、短引线或目标覆盖 warning。
- 本版平台验证为 Windows；跨平台/Node 20、22 完整矩阵仍在后续路线图，不从旧版结果外推本版。
- Codex Skills-only Plugin 独立于 MCP；本机初轮读到的 Skill 缓存仍为 0.2.0，MCP 实际版本由 doctor 确认。
- 下一阶段为可选本地 OCR locator，其后是一键交接包、DOM 定位与协作/平台完善，见[路线图](../roadmap.md)。
