# AgentCallout v0.6.1

2026-09-14。候选可视化核对 + Chromium 多引擎版本（roadmap v0.5.2 项顺延）。

## 本版功能

- **`preview-candidates`（CLI）/ `preview_candidates`（MCP，工具总数 16）**：把 locate-text/locate-dom 的候选 bbox 画为编号描边框+编号徽章渲染到源图，输出独立 PNG。把「多候选/低置信度必须确认」从读 JSON 变成看图选号。
- 候选预览是临时确认产物：无 sidecar、不进修订链、不自动生成批注；上限 100 个候选；标签文字 XML 转义。
- **Chromium 多引擎**：`browser status` 新增 `engines` 字段（Chrome/Edge 本机枚举，零下载）；`locate-dom --engine`（MCP `engine`）选择引擎；候选证据新增 `browser.engine` 与浏览器版本。
- 请求引擎未安装时返回 `DOM_ENGINE_UNAVAILABLE`；Windows 无 Chrome 的机器可走 Edge。
