# AgentCallout v0.5.0

2026-09-13。真实绿灯版本：清偿 DOM/OCR/lineage 三处测试债，完成 ADR-0004 宿主回归，Node 支持线上移。功能提交 `e092063`。

## 本版功能与修复

- **DOM 定位测试 fixture 化（大项）**：fixture 页面入库 `tests/fixtures/dom/`，测试运行时装入套件级临时目录——删除 `/tmp/dom-rt`、`file:///private/tmp/...` 与硬编码 Chrome 路径等机器本地依赖；Chrome 缺失的环境动态 skip 并打印运行时原因。
- **DPR 防御校验**：worker 在截图后断言全页 PNG 像素尺寸==CSS 页面尺寸（`deviceScaleFactor` 钉在 1），不一致返回 `DOM_DPR_MISMATCH`，不返回漂移坐标。
- lineage 错误分支测试补齐（无效源、原图缺失、目标父目录、被篡改 fork.json 降级处理）；`LineageError` 消息统一携带错误码。
- OCR：新增网络隔离回归（证明 fetch/http(s)/net/tls/dns 在离线 worker 上下文被阻断）；2 个真实安装测试保持 env 门控并获得**专用 CI job**（`ocr-real-runtime`）。
- **Node 支持线上移**：`engines >=22`（Node 20 已 EOL），CI 矩阵改为 22/24；决策记录见 decisions.md。
- README 显式声明输入资源上限（单图 ≤50 MB、≤4000 万像素，超限稳定报错）。
- 防漂移门禁：`check:docs` 加入 verify 链，PROGRESS/roadmap 与代码版本失同步即失败。
