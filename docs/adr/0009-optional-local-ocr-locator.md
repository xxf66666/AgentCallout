# ADR-0009：可选本地 OCR 定位器

- 日期：2026-09-06
- 状态：已接受，v0.3.0 实现中，尚未完成产品验收
- 依据：[本地中英文原型与失败证据](../research-ocr.md)

## 决策

OCR 作为独立 locator，现有 annotate/revise/render 不加载 OCR 引擎。选择已跑通的 Tesseract.js/core 7.0.0；默认安装不附带 WASM 或语言模型，仅附安装 manifest/lock 和启动代码。通过显式 `agent-callout ocr install` 获取固定依赖及本地 eng/chi_sim 模型。识别入口不下载、不静默修复模型，也不接受云图片处理地址。

运行时存放于版本化用户 cache，与业务截图目录分开。语言名限定为 eng/chi_sim，模型和运行时必须通过存在性、大小与 hash/版本校验。使用明确本地 langPath、关闭引擎缓存，避免上游缓存未命中时自动走 CDN。初始化和识别放入受控子进程并设置 deadline；错误只返回稳定、可操作信息，不透出原始引擎 stderr、模型字节或完整 OCR 文本。

提供三个层次：runtime 安装/状态与识别、纯文字匹配、面向 CLI/MCP 的图片定位。共享类型位于 `src/locator/ocr/types.ts`；定位器使用现有图片检查与 Sharp 的 EXIF 定向能力，绑定原始输入 hash、定向尺寸、可选 ROI 和缩放/预处理变换。识别读取完整本地源图或显式 ROI，不能使用 512px MCP 预览代替 OCR 输入。

## 匹配与证据

支持 exact/contains、中英文与重复候选。默认大小写不敏感，NFKC 与空白规范化；只消除相邻 CJK 字符间的 OCR 插入空白，保留英文词边界。exact 要求完整连续词语匹配，contains 可返回符号范围；缺少符号时标记 word precision，不能冒充精确字符坐标。

输出 not-found、unique、ambiguous 或 low-confidence，并保留候选、原始匹配文字、支持 word/symbol 索引、置信度与 bbox。多候选必须确认；默认置信度阈值 80 可由调用方调整，只是引擎分数的启发式界限，未经概率校准。低分不得偷偷丢弃，多结果不得默选最高分。结果可限制返回数量，但必须报告总数和 truncated。

候选 bbox 表示识别文字范围；若需要整个按钮或相邻说明文字的范围，必须由 Agent 查看确认，不能把文字框自动当成控件框。最终用户选择的候选仍转换为普通 AnnotationSpec，交给现有渲染器；不把 OCR 文本作为命令执行，也不自动调用 annotate。

## 验收

匹配单元测试覆盖中文断词、英文词边界、exact/contains、重复、低分、无结果、Unicode、符号/词范围、确定性和预算。定位层测试覆盖 EXIF、ROI/缩放逆映射、输入绑定、越界、透明图片与图片上限。运行时验证离线、缺/坏模型、初始化错误、超时终止、重复/并发安装与真实中英文识别。最后必须完成 CLI/MCP、干净安装和真实客户端定位后批注；原型不能替代这些门槛。

已知原型会漏掉蓝底白字保存按钮，也会识别出假图标文字。需继续验证预处理与 ROI 的可解释流程，保留失败和低置信度证据，不声称任意截图都能自动找到按钮。
